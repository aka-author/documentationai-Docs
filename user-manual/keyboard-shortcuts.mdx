## Commands at a glance

Every task in Erase & Rewrite can be started from the menu, from a toolbar button, or with a key combination; the table lists all three side by side and leaves a cell empty when an option is not available.

| Task | Menu command | Toolbar button | Keys |
| --- | --- | --- | --- |
| Open a folder | **File → Open a Folder…** | Open | <kbd>Ctrl</kbd>+<kbd>O</kbd> |
| Save the treemap to a file | **File → Save the Treemap As…** | Save | <kbd>Ctrl</kbd>+<kbd>S</kbd> |
| Close the program | **File → Exit** |  | <kbd>Ctrl</kbd>+<kbd>X</kbd> |
| Go up one folder | **Inspect → Up** | Up | <kbd>Backspace</kbd> |
| Open the folder on the map in File Explorer | **Inspect → Explore…** | Explore | <kbd>Ctrl</kbd>+<kbd>E</kbd> |
| Open the Recycle Bin | **Inspect → Expose the Bin…** | Expose the Bin | <kbd>Ctrl</kbd>+<kbd>B</kbd> |
| Read the folder again | **Inspect → Update** | Update |  |
| Stop reading the folder | **Inspect → Stop** | Stop | <kbd>Esc</kbd> |
| See the program version | **Help → About…** |  |  |

<Callout kind="info">

Update and Stop share one place on the toolbar and on the Inspect menu, but Stop is not a greyed-out Update. While the program is reading a folder, Update is replaced by Stop, and Update returns when the reading ends. There is no key for Update.

</Callout>

## When a command is greyed out

A command is available only when it can do something at that moment. Some commands grey out, and others disappear while the program is reading a folder.

- **Save** is greyed out until a folder has been read.
- **Up** is greyed out when the folder on the map is the one you opened, and also while the first read of a newly opened folder is still running.
- **Update** is greyed out until a folder has been read, and it is not shown at all while a read is running.
- **Stop** is not greyed out; it does not appear at all unless a read is running.
- **Explore**, the right-click **Move to Bin…**, and diving into a folder by clicking are unavailable while a read is running.
- **Open a Folder**, **Expose the Bin**, **Settings…**, **About…**, and **Exit** are unavailable while a read is running.

A command that is greyed out also does nothing if you press its keys.

## The same commands in every place

The program shows the same set of commands whether you use the menu, the toolbar, or the keys. Nothing is available only one way.
